# Quickstart · 端到端验证指南

> 目的：用可复跑的场景证明特性成立。数据形状见 [data-model.md](data-model.md)，接口见 [contracts/rpc.md](contracts/rpc.md)（思源侧见 [contracts/siyuan.md](contracts/siyuan.md)），实现细节不在此重复。命令以插件仓库 `package.json` 真实脚本为准，下表为预期形态。

## 前置条件

- Node ≥ 24.9.0、pnpm（宿主 workspace 要求）；dsh 检出 `github/deepseek-harness` `0.2.2-rc.1`
- 思源运行中（本机默认 `http://127.0.0.1:6806`，API 默认开启无需开关），已获取 **API Token**（思源 设置 → 鉴权 → API token），配置为插件 Config 项（Token 不写入日志/审计/状态文件）
- 隔离环境：独立 `DSH_HOME` + web profile + 独立端口（不碰真实环境与真实数据）
- 宿主已配置至少一个可用 LLM provider/model（D3 宿主通道）

## V0 · 构建与隔离安装（链路打通）

```powershell
npm run typecheck; npm test; npm run build; npm pack
node "<dsh-repo>\apps\cli\lib\bin.js" --profile web plugin add "<plugin>.tgz"
node "<dsh-repo>\apps\cli\lib\bin.js" --profile web --dump-config   # 仅证 bundle 入选；非严格只读
# 以隔离 DSH_HOME、独立端口启动测试 Host（冷启动，不假设热重载）
```

**预期**：typecheck/test/build 全绿；`dump-config` 显示 bundle 与 patch 行；Host 启动无装载错误（按 package.json → patch → exports → inject → 产物格式 → Host 日志顺序排障）；Client 产物内联 `biji.svg`（dataurl），运行时不请求外部图标资源。

## V1 · 消息操作栏按钮（FR-001）

**操作**：隔离环境发起一次对话，等待回复**完成**，hover 该条消息行。
**预期**：copy 与 branch 按钮之间出现「导出到思源」；仅定稿消息有该按钮（中断消息无）；重启 Host 后按钮仍注册且**无重复注入**。
**证据**：UI 截图 + Host 日志无 slot 注册错误。

## V2 · 弹窗、默认主题名与文档树（FR-002/003/004/005/006）

**操作**：点击导出按钮；观察标题输入框；展开并选择文档树的笔记本/子文档。
**预期**：< 1s 打开弹窗；标题先显示「正在生成默认主题名…」随后**自动填入** LLM 默认值（用户已编辑则不覆盖）；树懒加载（`tree.list`），选中即目标落点；曾成功导出过则 `lastPath` 为默认选中（首次为 null，可选笔记本根）。
**边界**：stale 响应不覆盖新弹窗状态；「导出」按钮在 `ready/degraded-ready` 前不可用。

## V3 · 真实写入思源（FR-007/009/012 + SC-003/004）

**操作**：确认主题名与路径 → 点击「导出」。
**预期**：所选路径下**新建**以主题名命名的文档；打开即为结构化笔记——清晰标题分节、要点带小图标（✅ 📌 ⚠️ 💡 等）、代码块与列表原样保留；反馈区显示落点（FR-012）；再次打开弹窗默认路径 = 本次位置（FR-006）。
**抽样**：按 SC-003 评估 ≥90% 无需二次编辑；SC-004 默认主题名 ≥80% 免改。
**证据**：思源中打开文档截图 + 第二次导出的默认路径。

## V4 · 幂等防重（FR-011 + SC-006）

**操作**：按钮 loading 期间重复点击；同消息重复 `export.open`；writing 中重复 commit。
**预期**：**只产生一篇**笔记；同键 open 不重复调 LLM（Host 调用计数为 1）；重复 commit 被幂等拒绝而非二次写入。

## V5 · LLM 通道与 FR-013（省 token 硬约束）

**操作 A（真实小请求）**：`export.open` 触发生成，验证 provider/model 经 `listProviders()/listModels()` 解析成功、生成完成。
**操作 B（输入裁剪复核）**：检查该次真实请求的 prompt（测试日志或 mock 捕获）。
**预期 B**：输入 = **该条单次输出 + 固定指令模板**，**不含** Session 历史、用户提问、工具输出（FR-013；`tests/unit` 已有负向断言，此处真实链路复核）。
**失败注入**：故意配置无 adapter 的 provider → 弹窗显示 `llm-adapter` 引导文案，**不误报成功**。

## V6 · 失败与重试（FR-010 + US3 全场景）

| 步骤 | 操作 | 预期 |
|---|---|---|
| a | 关闭思源后导出 | `siyuan-connect` 文案 + 「重试」；**title/target 保留**；恢复思源后重试成功且仅一篇（SC-006） |
| b | 模拟 LLM 超时/断开模型 | 进入 `degraded-ready`：标题=首行截断、正文=原文，仍可导出（US3-2） |
| c | 生成中关闭弹窗 | `cancel` 中止模型流；**无半成品文档**（edge case） |
| d | 导出前删除目标文档 | commit 报 `siyuan-path`，引导重选路径 |

## V7 · 同名与长内容（Edge cases）

- 同名路径导出两次 → 两篇独立文档，互不覆盖（FR-007）。
- 数万字长回复 → 正常导出不截断（edge case）。

## V8 · 侧栏入口与设置面板（FR-014/015/016/024 + SC-010）

**操作**：在左侧栏找到带 `biji.svg` 图标的「导出设置」→ 点击 → 在主工作区打开设置 tab；修改「默认存放路径」（展开树→选节点）；切换「导出时显示弹窗」。
**预期**：
- 入口图标正确渲染、有可访问名称（hover/读屏可读）；模拟 `biji.svg` 加载失败后入口仍有可访问名称；点击不出现模态遮罩，对话仍可操作（tab 切换而非阻塞）。
- 设置页显示当前开关与默认路径；修改**即时生效并保存**（无全局「保存」按钮），保存期间该项禁用，成功后就地确认。
- 默认路径只能从思源树选择，不出现本机文件路径输入；父级无效/笔记本被删 → `siyuan-path` 提示且不落库。
- 思源关闭时打开设置：已保存值仍显示；修改保存报 `siyuan-connect` 并可重试。
- 键盘：Tab 可达入口与开关，方向键/Enter 操作树，Esc 不误关面板；中英文切换文案完整。
**证据**：UI 截图（桌面 + 窄宽）+ 键盘操作录屏 + `prefs.get` 返回与 `prefs.json` 对照（Token 不在其中）。

## V9 · 静默导出成功（FR-017/018/019/020/021 + SC-007/008/009）

**操作 A（有默认路径）**：设置默认路径 → 关闭「显示弹窗」→ 回到对话，点击某条已定稿回复的导出按钮。
**预期**：**不打开弹窗**；按钮立即呈加载/运行态且不可重复触发；可继续输入/发送/切换面板；完成后右下角 toast 显示落点，~6s 自动消失；笔记落在默认路径。
**操作 B（无默认路径）**：清空默认路径（且从未成功导出）→ 关闭开关 → 点击导出。
**预期**：落在 `lsNotebooks` 第一本未关闭笔记本的根目录；toast 显示该落点。
**操作 C（降级）**：模拟 LLM 失败 → 静默仍写入原文；toast 标注「未能自动排版」并给落点。
**证据**：计时（样本 20 次，19/20 即 95% <30s；不足 20 次记「抽样，未达统计口径」）+ 思源落点截图 + 对话可继续操作的录屏。

## V10 · 静默失败与重试（FR-020/023）

| 步骤 | 操作 | 预期 |
|---|---|---|
| a | 默认路径选中文档后，在思源删除该父级，再静默导出 | 失败 toast 含 `siyuan-path` 原因 + 「重试」；**不自动打开弹窗**；**不改道**到根目录 |
| b | 关闭思源后静默导出 | 失败 toast 含连接原因 + 「重试」；恢复思源后点「重试」成功，**只产生一篇** |
| c | 思源无任何笔记本 | 失败 toast 提示先创建笔记本；设置页路径选择显示空态 |
| d | 生成中关闭 dsh 窗口 / 重启宿主 | 不留下半成品笔记；重开后可重新发起（无持久半成品） |
| e | 失败 toast 内点「打开设置」 | 打开设置 tab（非弹窗），可修正路径 |

## V11 · 并发与生命周期（FR-019/025 + SC-011）

**操作**：对 3 条不同回复依次点击静默导出；期间切换会话再切回；再对同一条回复连点两次。
**预期**：3 条各自生成/写入、互不阻塞，每条只产生 1 篇笔记（重复 0、丢失 0）；切换会话后该按钮仍保持加载态并最终 toast；同一回复的第二次点击不产生第二篇（`alreadyRunning=true` 或幂等命中）。
**证据**：思源中 3 篇独立文档 + Host 任务计数 + 会话切换录屏。

## V12 · 偏好持久化与迁移（FR-022）

**操作**：设置默认路径与关闭开关 → 重启 Host → 重新打开设置与对话导出；再用一份 v1 `prefs.json`（含 lastPath/draft）启动。
**预期**：重启后开关与默认路径保留；对话点击直接静默；v1 文件自动迁移为 v2 且 **lastPath/draft 不丢**，`showDialog` 默认 true；损坏 JSON → 回退默认值且功能可用（不崩溃）。
**证据**：`prefs.json` 前后对照 + 迁移单测 + 重启后设置页截图。
